# LogOS.API.Ports

Local navigator for curated port entrypoints.

- `Physical.agda`: physical and locality-facing interfaces
- `UniversalityArchitecture.agda`: default universality architecture basis
- `Universality.agda`: explicit architecture-first universality surface with `LOG` namespace
- `Valuation.agda`: quantitative adapter and scale-boundary surface
- `LTDecorations.agda`: displayed and totalised LT-port packaging
- `Dependent.agda`: dependent-first locality surface kept off the default port facade

Use `LogOS/API/Ports.agda` for the default facade. Import the sibling modules
directly when you want an explicit optional storyline.
